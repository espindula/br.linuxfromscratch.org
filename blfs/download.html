Desenvolvimento Atual

Este é o livro BLFS no estado atual de desenvolvimento dele. As instruções geralmente são estáveis, mas podem ocorrer mudanças que quebrem a construção temporariamente.

Instantâneos (somente em inglês) renderizados diariamente podem ser baixados. Ou baixe o XML do livro (em português) a partir do repositório Git e renderize-o você mesmo(a):

git clone https://github.com/espindula/br-blfs.git br-blfs-git

Desenvolvimento Atual Systemd

Este é o livro Systemd do BLFS no estado atual de desenvolvimento dele. As instruções geralmente são estáveis, mas podem ocorrer mudanças que quebrem a construção temporariamente.

Instantâneos (somente em inglês) renderizados diariamente podem ser baixados. Ou baixe o XML do livro (em português) a partir do repositório Git (instrução acima) e renderize-o você mesmo(a).

Depois que os pré-requisitos listados no arquivo INSTALL forem instalados, use 'make REV=systemd' para renderizar o livro. Informações adicionais estão listadas nos arquivos README e RENDERIZAR.txt.

Pacotes para BLFS

BLFS has a list of packages which you can download. Please use the versions which are listed in the book; these are tested versions which are known to work with each other. In addition to the packages you will need to download some patches that are also listed in the book. There are several ways to download the packages.

Hunt and Peck

When a package is not available from the location listed in the book, some other places to try are:

  • A search for the full package name in google or your favorite search engine
  • Debian Package Search Page

BLFS HTTP/FTP Sites

If the above methods are not available to you, the packages are also available individually on the following ftp and http mirrors.

  • ftp://ftp.lfs-matrix.net/pub/blfs/ (California, USA, 200Mbps)
  • http://ftp.lfs-matrix.net/pub/blfs/ (California, USA, 200Mbps)
  • ftp://ftp.osuosl.org/pub/blfs/ (Oregon, USA, 310Mbps)
  • http://ftp.osuosl.org/pub/blfs/ (Oregon, USA, 310Mbps)
