Transferência do SLFS

Lançamentos do SLFS

No sítio do SLFS, o livro é lançamento contínuo e frequentemente é renderizado logo depois da última submissão de Git ou lote de submissões no fonte Git. No entanto, existem lançamentos em HTML fragmentados. Cada um deles é versionado com os primeiros quatro ou mais caracteres únicos do resumo de Git ao tempo do lançamento. Existem lançamentos instáveis (ou pré-lançamento) e lançamentos estáveis. Se não quiser baixar um lançamento, você também consegue renderizar o livro você mesmo(a). Lançamentos estáveis também mostrarão como renderizar uma cópia local da versão estável em cada listagem do lançamento do Github.

Git do SLFS

O SLFS pode ser obtido a partir do repositório Github:

git clone https://github.com/glfs-book/slfs

Você consegue atualizar o fonte fazendo:

git pull

Renderizando o livro do SLFS

A renderização funciona da mesma maneira que nos livros *LFS. Leia-se o INSTALL.md incluído para descobrir quais pacotes você precisa para a finalidade de renderizar o livro da maneira que quiser. README.md também fornece informações como opções de renderização que você possivelmente queira configurar.

Se você quiser renderizar a versão Systemd do livro, por exemplo, execute:

make REV=systemd

Pacotes para o SLFS

O SLFS tem uma lista de pacotes que você consegue baixar. Por favor, use as versões listadas no livro, a menos que você saiba o que está fazendo.
