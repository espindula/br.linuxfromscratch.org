Lançamentos do GLFS

No sítio do GLFS, o livro é lançamento contínuo e geralmente é renderizado logo depois da última submissão de Git ou lote de submissões no fonte de Git. No entanto, existem HTML fragmentadas lançamentos. Cada um deles é versionado com os quatro primeiros ou mais caracteres únicos do Git hash ao tempo do lançamento. Existem lançamentos instáveis (ou pré-lançamento) e lançamentos estáveis. Se não quiser baixar um lançamento, você também consegue renderizar o livro você mesmo(a).

Git do GLFS

O GLFS pode ser obtido a partir do repositório GitHub:

git clone https://github.com/glfs-book/glfs

Você consegue atualizar o fonte fazendo:

git pull

Renderizando o livro do GLFS

A renderização funciona da mesma forma que com os livros *LFS. Leia o INSTALL.md incluso para descobrir quais pacotes você precisa para a finalidade de renderizar o livro da maneira que você quer. README.md também fornece informações como opções de renderização que você possivelmente queira configurar.

Se você quiser renderizar a versão Systemd do livro, por exemplo, execute:

make REV=systemd

Pacotes para GLFS

O GLFS tem uma lista de pacotes que você consegue baixar. Por favor, use as versões listadas no livro, a menos que você saiba o que está fazendo.
