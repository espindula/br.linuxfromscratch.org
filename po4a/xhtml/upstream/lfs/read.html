Translations

The LFS book has been translated in various languages. Note that these translations were done by volunteers and may contain translation errors which the LFS team cannot control. In that case, contact the translator directly.

Please note that all versions of LFS <= 5.1 contain instructions that create an English-only system and therefore will require additional undocumented work (i.e. setting LANG and font) in order for the system to be useful in another language.

If you have translated the LFS book or if you are aware of translations not in this list, please send us an e-mail to the site webmaster with the URL to the translation.
